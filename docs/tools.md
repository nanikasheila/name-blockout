# 使う道具とアドオンの検討

name-blockout に取り入れる候補を、1 件ずつ、ライセンス・今の Blender（5.x）で動くか・画面なし（`blender -b`）で台本から使えるか、で見ます。素材と同じく、**無料で商用にも使えるもの**だけを使います。有料のもの・利用条件が素材の関所（[assets.md](assets.md)）に合わないものは、使わない理由を書いて残します。

- 調べた日: 2026-11-27。ライセンスと対応の版は、その日に配布元のページで読んだものです。入れるときに、もう一度その版のページで確かめます。
- 「試し」は、作者の PC（Blender 5.3）で、普段の設定に入れずに別プロファイル・別の venv で動かした結果です（2026-11-27）。

## まとめ（試した 3 つ）

| 何を作るか | 道具 | 結果 |
| --- | --- | --- |
| 素材のない細かい物（門柱・手すり・家具） | build123d | いちばん使える。寸法から面取りつきの形が出る。Blender の外で作って読む |
| 中景の家並み | Building Tools | 使える。数値から家が一気に立つ。近景には簡素 |
| 木 | Sapling Tree Gen | 幹と枝だけ。葉は線が細かすぎて、茂みの形にならない |

どれもまだ name-blockout には組み込んでいません。組み込むときは、作った形を素材（`素材.json`、ライセンスつき）として置き、道具そのものは同梱しません。

作者の言葉（2026-11-27）: 「木のような自然物は輪郭線ではなく、陰での表現を優先します。」「アドオンは必要はないでしょう。」

- 木を作るアドオン（Sapling Tree Gen など）は組み込みません。木は道具の簡単な形（茂みの丸い塊と幹）のまま、輪郭線なしで、光の面と影の面のトーンと落ちる影で描きます（[phases.md](phases.md) の線画）。
- 場所のまわりの市街地（家並み）も、Building Tools ではなく道具の Python（`town.py`）で作りました。アドオンなしで、同じ種から同じ街が出て、Blender なしでテストでき、計画と俯瞰図に家の位置がそのまま残ります。
- 下の表は調べた記録として残します。

name-blockout が作るのは、白黒の線・トーン・ベタの背景です。色つきのテクスチャ、UV、ゲーム用の間引きや書き出しは要りません。効くのは「測れる物を寸法どおりに詳しく作る」「木のように測れない物の形を得る」「建物や部屋を図面から立てる」「描いた絵を別の目で確かめる」の 4 つです。

## 漫画の背景では要らないもの

AutoRemesher・RetopoFlow（面の作り直し）、xatlas（UV 展開）、Material Maker・ArmorPaint（色つきテクスチャ）、meshoptimizer・glTF-Transform（ゲーム用の間引きと書き出し）、PyMeshLab（メッシュの修理。生成を使うことになったら見直す）。どれもゲーム用のキャラクターを作る流れのためのもので、白黒の線とトーンにはほとんど効きません。
