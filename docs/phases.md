# 要求開発 → 設計（Blockout）→ 開発

name-blockout は背景を 3 つのフェイズで作ります。一発で完璧は狙いません。ネームの案出しでは設計まで、作画に移ると決めたコマだけ開発に進みます。

```
指示.json（name-studio）
   │
   ▼
要求開発 ── 点検（ルール）→ 質問 1〜2 問 → 答え → 確定（版）
   │                ▲
   ▼                │ Blockout を見て判断が変わったら戻る
設計（Blockout）── 組む → 照合（数値）→ 描き出す → 案/ と 背景.json
   │
   ▼
開発（本番）── 同じカメラと配置のまま、物を詳しく、場所・時間帯・光・質感、漫画の線とトーン
```

## 要求開発

指示書を、モデルを作る前に確かにします。指標は「組んでから分かる穴や矛盾が減ること」。

1. **点検（`name-blockout check`）**: AI を使わない決まったルール。同じ指示書なら同じ結果。
   - error（そのままでは組めない）: 消失点の数と透視の数が合わない、消失点 1・2 がアイレベルから外れている、3 点の三角形が鋭角でない、書いた道具のカメラの計算と食い違う、素材がない、場所の向きと消失点が合わない。
   - warn（矛盾）: 「あおり」なのにアイレベルが上、「俯瞰」なのに下、レンズが極端（12mm 未満・300mm 超）、地面の物がアイレベルより上で終わる、人物の大きさとカメラの高さが合わない、人物や物の大きさから出したカメラの高さがありえない（屋内 0.1〜2.6m・屋外 〜60m の外。その値は選択肢に出さない）、同じ場所の隣のコマで時間帯・天気が違う、開発に進むのに時間帯がない。
   - info（決まっていない。仮の値で組む）: カメラの高さ、場所、天気。
2. **質問**: 見つかったことのうち質問を持つものを、error・warn を先に **1〜2 問ずつ** 選択肢つきで出します（`--questions`）。選択肢には道具が計算した目安を入れます（例: 人物の大きさから 1.33m、バンのふつうの大きさから 0.81m）。「おまかせ」を選ぶと仮の値のまま、その値は案のメモと `plan.json` の `assumptions` に残ります。
3. **答え（`name-blockout answer --set path=value`）**: `要求/<コマ>.json` の下書きに入ります。指示書は書き換えません。指示書が空けている所だけを埋め、後で作者がネームの道具で同じ所を決めたら指示書が勝ちます（その答えは「置き換わった」と報告）。
4. **確定（`name-blockout confirm`）**: 中身が前の確定版と違えば版が上がります。設計と開発の照合はこの確定版に対して行います。
5. **見て決める**: 言葉で決まらない点は、Blockout の下見を並べて選びます（設計を 2〜3 案出す: 次の段階で name-studio の作画の欄から）。

## 設計（Blockout）

`name-blockout blockout 指示.json` で、コマごとに:

1. 計画（`plan.py`）: 定規からカメラ、地面の格子（遠くほど粗く、線が詰まりすぎない）、物の箱、人物の人形、3 点で物がなければ縦の柱、物の距離帯（近景・中景・遠景）、遠景の層（`far.py`: 全天球の画像・種から作る街並み・山並み・木立）、屋内なら部屋（`room.py`: 床・壁・天井・窓）、使った素材のクレジット。全部データで、Blender なしで作れます。
2. 組む（`blender/scene.py`）: 計画をそのまま Blender に。同じ指示なら同じシーン。
3. 照合（`blender/measure.py`・`verify.py`）: Blender 自身の投影（`world_to_camera_view`）で、アイレベル・消失点（カメラの向きと、場の実際の辺が集まる点の 2 通り）・物と人物の外形を測り、**指示書から取った目標**と比べます。name-blockout のカメラの式とは別の道で測るので、どちらかの間違いが出ます。

   | 照合 | 合格 |
   | --- | --- |
   | アイレベル（左右の端） | 長い辺の 0.5% 以内 |
   | 消失点 | 絵の 9 か所から引いた線の向きのずれが 0.3° 以内（コマの外の遠い点も線の向きで判定） |
   | 物の範囲 | 重なり（IoU）85% 以上（大きさか素材が決まっている物は参考） |
   | 人物の足 | 長い辺の 1% 以内（頭のずれは参考として出す） |

4. 描き出し（`blender/render.py`）: Cycles の CPU（どこでも動く）と Freestyle で、完成（白地）・線画（透明地）・トーン（面の向きで 3 段のグレー）。遠景の層があれば遠景（遠景の帯だけ、全天球の画像の上に）。線は距離帯ごとに細く、トーンは遠いほど明るく。既定 150dpi の下見。
5. 渡す: `案/<コマ>/<番号>/` に画像、`依頼/<id>/背景.json` に 1 案 1 件（name-studio の作画の欄でそのまま採用・修正・頼み直しができる）。照合の結果は案のメモに 1 行で。組んだものは `blockout/<コマ>/<番号>/`（plan.json・measured.json・check.json・scene.blend・built.json）。

## 戻る道とやり直す範囲

Blockout を見て判断が変わるのは当たり前として作ります。指示書や答えを直してもう一度 `blockout` を呼ぶと、前に組んだときの中身（`built.json`）と比べて道具がやり直す範囲を決めます（`scope.py`、`name-blockout scope`）。

| 変わった所 | やり直し |
| --- | --- |
| 描く範囲・定規・カメラ・場所・物・人物・背景の言葉 | 設計から（Blockout を組み直す。変わっていない物は `objects.kept` で分かる） |
| 見た目（時間帯・天気・光・質感）・描き出し・stage | 開発だけ |
| 名前・メモ・セリフ・hint | なし |

`--only-changed` を付けると、設計に関わる変更がないコマは組み直しません。前の版の案は消さずに残るので、見比べられます。

## 開発（本番に近づける）

作画に移ると決めたコマだけ（`stage: "develop"`、`name-blockout develop 指示.json`）。設計で合格したカメラと配置は動かさず（同じ照合をもう一度通す）、光と材質を足します。既定 300dpi（指示の dpi まで）。

1. 光（`look.py`）: 言葉から決まった計算で数値に。
   - 太陽: 日付（なければ春分）・時間帯・緯度経度（なければ東京）・北の向き（なければ +Y）から、高さと方位。時間帯はその日の日の出・日の入りから決まる地方太陽時（明け方 = 日の出 15 分前、朝 = 日の出 2 時間後、昼 = 12 時、午後 = 15 時、夕方 = 日の入り 1 時間前、日暮れ = 日の入り 20 分後、夜 = 太陽なし）。
   - 天気: 晴れ・くもり・かすみは日差しあり（くもりほど影がやわらかい）、どんより・雨・雪・霧は日差しなし。
   - 時間帯がなく `look.light.key`（順光・逆光・左から・右から・真上）だけなら、カメラから見たその向きに光を置きます。
   - 屋内（`look.setting: "indoor"`、なければソファ・部屋・机などの言葉から仮に屋内）: 時間帯の太陽は使わず、`look.light.key` の明かりで照らします。窓から（左から低く、夜は消える）・天井の明かり（上からやわらかく、既定）・街灯。地面は床になります。天井の明かりのときは、場所の素材の天井と屋根（アイレベルより上にある物）は光を通します（部屋の中の明かりの代わりなので、家の上からの日差しにしない）。
2. 材質（`materials.py`）: ライブラリの材質は「3D の材質」と「漫画での描き方」の組です。光の当たる面のトーン、影の面のトーン、ベタにするか、線を描き込むかを持ちます（`name-blockout materials` で一覧）。物には `look.materials` で割り当て、なければ名前から推し量ります（倉庫 → トタン、バン → 黒い塗装 など。仮の値として残ります）。地面は `ground`、部屋の壁と天井は `walls` です。地面と床の既定は「白地」（光の面は白のまま、影だけ薄いトーン）で、一面を中くらいのグレーにはしません。場所の素材（.blend）の物は、物と材質の名前（英語も。roof → 瓦、glass → ガラス、leaf → 草 など、決まらなければコレクションの名前）から材質を推し量り、ガラス以外でとても暗い色の塗装はベタにします。ソーラーパネル・ルーバーなど細かすぎる物は外形だけを描きます。広く平らな面（厚さ 0.4m 以下・12m² 以上: 敷地の地面・芝・テラス・平らな屋根）は、ベタ・ガラス・水でなければ白地にします。素材の中の部分は、その部分の名前で割り当てられます（例: 椅子の素材の「座面」を黒い塗装に）。
3. 場所の素材（`place`）: カメラ・ライト（開発が自分で照らす）と、人の代わりの人形（名前が D_ で始まる・dummy・人形）は読み込みません。`.blend` で描かない設定（hide_render）の物も読み込みません。`place.moves` で中の物を動かし（物の名前・位置・向き、`show` で描かない設定を外す）、`place.hide` で描かない物を外せます。場所があっても屋外でアイレベルがコマの中を通るなら、場所の先に遠景の層を置きます。
3. 素材への差し替え: 物に素材（`素材.json` の thing。名前か `asset` で）があれば、開発では箱の代わりに素材を置きます。箱の最初の辺の向きに回し、素材の正面（−Y）をカメラへ向け、縦横高さを同じ割合で縮めて箱に収め、箱の底に立てます。Blockout は箱のまま（速さのため）。
4. 描き出し（`blender/develop.py`）:
   - 開発の案は、指示書の `output.take` が Blockout の案ならその番号を上書きせず、次の番号に描きます。
   - 光: 全部を白い艶消しにし、太陽だけで照らします。やわらかい光（光源の角度が 5° より大きい）はサンプルを 4 倍にし、ノイズ除去をかけます（影の縁がざらつかないように）。日の当たらない所（向こうを向いた面と落ちる影）が影です。影を受ける地面はこのときだけ置きます（線には出ません）。
   - トーン: 材質ごとに、光の面のトーンと影の面のトーンを平らに塗り、影の所だけ影のトーンにします。ベタは黒です。明け方・日暮れ・夜は全部が影のトーンになり、空にもトーンが入ります。
   - 影: 影だけ（透明地に薄いグレー）。
   - 線画は Blockout と同じで、遠いほど細くなります。木の茂み（材質が草の丸い部品、場所の素材なら葉・茂みの名前の物）は外形だけを描き、中の面の折り目は線にしません。線の太さの 3 倍より短い線（小さな面の折り目の点）も描きません。完成は、白地にトーンと線画を重ねたものです。ベタの上の線は白で描きます（黒に黒では消えるので）。
5. 光の照合（描き出した 光 を、Blender の当たり判定で作った答えと比べる）:
   - 地面: 地面に立つ物と人物ごとに、太陽と反対側（影が落ちるはずの地面）と太陽の側（日が当たるはずの地面）の点を、カメラから見えるものだけ確かめます。光が全部さえぎられる点・全部届く点だけを使い（やわらかい光の半影は除く）、光が真上に近い（70° より高い）ときは影が足もとに入るので地面は確かめません。75% 以上が合えば合格。
   - 面: 絵の全体に 32×20 の点を取り、カメラから見える面が光の向こうを向いているか、光との間に何かあれば影、光の方を向いて間に何もなければ日なた、として確かめます（影の縁・やわらかい影の半影・かすめる角度の点は除く）。85% 以上が合えば合格。
   - 試せる点が 1 つもないとき（日差しも明かりもない、コマの中に何も見えない）は「照合せず」と書きます（黙って合格にしない）。

要求の点検（開発のコマだけ）: 屋内か屋外か決まっていないのに屋内らしい言葉がある（info。屋内・屋外の選択肢）、屋内の明かりがない（info。天井・窓・街灯）、時間帯がない（warn）、屋外で場所・日付・北の向きが決まっていない（info。北は「日差しを右から」などの選択肢で）、光の向きの指示と太陽が合わない（warn。合う北の向きを選択肢に）、材質が決まっていない物（info。名前から推した材質を選択肢に）、ライブラリにない材質（warn）。

まだのもの: 物を素材の詳しい版に差し替える（素材の ID は同じで細かさの段を上げる）、線の描き込み（`lines: detail`）を実際の線にする、CSP のレイヤーへ分けて渡す。
